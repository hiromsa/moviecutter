## [v0.0.1-beta.17+376505e] - 2026-09-29
### 追加・改善機能
- **IN / OUT 位置の左右微調整ボタンの実装 (`|< IN[ ] >|`, `|< OUT[ ] >|`)**:
  - IN入力ボックスとOUT入力ボックスそれぞれの左右に、直感的な `|<` (1フレーム戻す) / `>|` (1フレーム進める) ステップボタンを新設。
  - 通常クリックで 1フレーム単位（FPS基準）、Shift+クリックで 1秒単位の高精度微調整に対応。
  - 微調整時にメイン動画プレイヤーも該当フレームへ同期シークするため、画面上で目的のシーンを確認しながらミリ秒単位で追い込み可能。
  - ブラウザ標準の上下スピンボタン（▲▼）を非表示化し、押し間違いや操作ストレスを解消。
- **動画再ドラッグ＆ドロップ用点線オーバーレイの完全対応**:
  - 動画をすでに読み込んだ後でも、別の動画ファイルを画面にドラッグした瞬間に、鮮やかなシアンの点線枠と「新しい動画をドロップして差し替え」オーバーレイが全面に表示されるよう改善。
  - ドラッグカウンターを用いた確実な判定により、子要素によるチラつきのない安定したドラッグ＆ドロップ体験を実現。


## [v0.0.1-beta.18+30b4706] - 2026-09-29
### 追加・改善機能
- **画像のみ・音声のみの取り込み＆静止画＋音声動画化（Twitter/X投稿用MP4生成）**:
  - 音声ファイル（MP3, WAV, M4A, AAC, FLAC等）を直接ドラッグ＆ドロップ可能に。取り込み時に高品質なスタジオアートワーク画像をCanvasで自動生成し、裏で音声が再生される静止画プレビューを実現。
  - 画像ファイル（PNG, JPG, WebP等）の取り込みにも対応。音声がある場合はカバー画像として即座に差し替え、画像のみの場合は音声を待受。
  - プレビュー画面右上に「画像変更」ボタンを配置し、いつでも手持ちのイラストやアルバムアートにワンクリックで差し替え可能。
  - FFmpeg.wasmに静止画＋音声合成エンジン（`-loop 1 -c:v libx264 -tune stillimage -preset ultrafast -c:a aac -pix_fmt yuv420p`）を新設し、Twitter/XやYouTube等で直接アップロード・再生可能な高品位MP4動画を瞬時に出力。
- **最初から最後まで一発全選択機能 (`All` / `Ctrl+A`)**:
  - クイック選択グループに「全選択」ボタン（`Icons.maximize`）を新設。
  - クリックまたはショートカットキー `Ctrl+A` / `Alt+A` / `A` で、動画・音声の最初から最後まで（0秒〜全尺）を一瞬で範囲選択可能。全体をそのまま動画化したり、全体から微調整したい場合に圧倒的な作業効率を実現。
