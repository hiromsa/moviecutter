# UI 仕様書 (UI Specification)

## 1. 概要
MovieCutter は、既存の動画から必要な部分を素早く切り取り、AIツール（画像・動画生成AI）などでの続きの制作を加速するための軽量かつ直感的なWebアプリケーションです。

## 2. デザインコンセプト
- **テーマ**: Modern Sleek Dark Studio（Apple / Linear / Runway に着想を得た洗練されたプロフェッショナルダークUI）
- **タイポグラフィ**: 
  - 見出し・ブランドロゴ: `Outfit` (幾何学的で洗練されたモダンフォント)
  - 本文・UI要素: `Plus Jakarta Sans` (高い可読性と透明感)
  - 時間コード・数値: `JetBrains Mono` (等幅・高精度)
- **ベクターアイコンシステム (`src/ui/icons.ts`)**:
  - 絵文字によるチープ感を排除し、Lucide / Heroicons スタイルの統一された線幅（stroke: 2px）のインラインSVGベクターアイコンを採用。
  - 各種操作（切り取り、再生/停止、コマ送り、ジャンプ、ズーム、カメラ、AIスパークル等）を視覚的に洗練。
- **アクセントカラー & 発光 (Glow)**:
  - メインアクセント: Vibrant Cyan / Deep Indigo (`#06b6d4`, `#6366f1`)
  - 切り取り範囲セレクター: Emerald Accent (`#10b981`)
  - 警告・再生ヘッド: Vivid Rose Red (`#f43f5e`)
  - AI連携アクション: Electric Purple (`#a855f7`)
- **レイアウト**:
  - ヘッダー（シザーロゴ、ブランド名、タグライン、バージョンバッジ、GitHubリンク、クイックガイド）
  - メインビューポート（動画プレビュー・オーバーレイ、洗練されたパルス発光のクラウドアップロードドロップゾーン）
  - タイムラインビュー（サムネイルリール、イン点/アウト点ハンドル、現在再生ヘッド、時間ルーラー）
  - クイックコントロールバー（再生/停止、コマ送り/コマ戻し、In/Out設定・ジャンプ、再生速度）
  - エクスポートパネル（切り取り動画の書き出し、ラストフレーム/現在フレームのPNG書き出し）
  - ステータスバー（FFmpeg読み込み状況、処理進捗、ファイル情報）

## 3. 主要UIコンポーネント構成
1. **HeaderComponent (`src/ui/Header.ts`)**
   - ロゴ、タイトル
   - バージョンバッジ (`v0.0.1-beta.X`)
   - ドラッグ＆ドロップファイル入力ボタン
2. **VideoPlayerComponent (`src/ui/VideoPlayer.ts`)**
   - HTML5 `<video>` 要素
   - 再生/一時停止、シーク
   - アスペクト比自動調整
   - **プレビュー＆IN/OUTサイドバーの横2分割レイアウト**:
     - **左側（メインビュー）**: 快適な映像視聴とシーク・HUD時間表示が可能なメイン動画プレイヤー。
     - **右側（IN / OUT プレビューサイドバー）**:
       - **上段（IN 開始点カード）**: 選択した開始点のフレーム画像サムネイルとタイムスタンプを表示。カードクリックで開始点へ即座にジャンプ移動。
       - **下段（OUT 終了点カード）**: 選択した終了点のフレーム画像サムネイルとタイムスタンプを表示。カードクリックで終了点へ即座にジャンプ移動。
       - 切り取り範囲の設定・微調整に合わせて自動でキャプチャ更新（デバウンス制御）。未設定時はスマートなプレースホルダーを表示。
   - **動画再ドラッグ＆ドロップ用オーバーレイ**:
     - 初回読み込み後でも、新しい動画・音声・画像ファイルを画面にドラッグした瞬間に鮮やかなネオンシアンの点線枠と「新しい動画・音声・画像をドロップして読み込み」オーバーレイが浮き上がり、次々とファイルをスムーズに差し替え・切り取り可能。
   - **音声のみ・画像のみの取り込み＆静止画＋音声動画化モード**:
     - **音声のみの場合**: MP3, WAV, M4A, AAC, FLAC等の音声を取り込むと、波形解析と同時にスタイリッシュなスタジオアートワーク（ジャケット画像）を自動生成してプレビュー。裏で音声が再生される。
     - **画像のみの場合**: PNG, JPG, WebP等の画像をドロップするとカバー画像としてセットされ、裏で流す音声ファイルを待受。
     - **画像の差し替え**: プレビュー右上の「画像変更」ボタンまたは画像ドラッグ＆ドロップで、いつでも好きなイラストやアルバムアートに差し替え可能。
     - **Twitter/X用動画化**: 静止画＋音声から、Twitter/XやYouTube等で直接投稿・再生できるMP4動画（H.264 + AAC + YUV420P）を瞬時にエクスポート。
3. **TimelineComponent (`src/ui/Timeline.ts`)**
   - **タイムライン統合ツールバー（再生・視聴・表示調整の全集約）**:
     - **再生トランスポート群**: 1フレーム戻る (`◀ 1f`)、再生 / 一時停止 (`Space`)、1フレーム進む (`1f ▶`)
     - **ループ切替**: 選択範囲ループ再生トグル (`🔁 ループ: ON/OFF`)
     - **キャレットジャンプ**: キャレットを開始地点 (`Inへ`) / 終了地点 (`Outへ`) にジャンプ
     - **再生速度セレクター**: 0.25x, 0.5x, 1.0x, 1.5x, 2.0x
     - **プレビュー音量コントロール**: ミュート切替ボタン、音量スライダー (0%〜100%)、パーセント表示
     - **タイムラインズームコントロール**: 縮小、ズームスライダー (1.0x〜10.0x)、拡大、等倍(1.0x)リセットバッジ
   - 横スクロールコンテナ（ズーム時にスムーズな横スクロール、再生ヘッドの画面内自動スクロール追従）
   - **ルーラー領域 (時間表示部)**:
     - ハンドルに邪魔されず、キャレット（再生ヘッド）を直接クリックまたはドラッグしてシーク可能。
     - 再生ヘッドの三角つまみはルーラー上部まで突出。
   - **トラック領域 (サムネイル・波形部)**:
     - **範囲ドラッグ選択**: キャレットの位置にかかわらず、トラック上の任意の場所（キャレットの真上を含む）からドラッグすることで、開始点(In)〜終了点(Out)を一発で範囲指定可能。
     - **クリック時**: 範囲を変更せず、キャレットのみをクリック位置へ移動。
     - **ハンドル微調整**: Inハンドル、Outハンドルを個別にドラッグしてミリ秒単位で微調整。
   - **ハンドルの完全位置一致**:
     - Inハンドル、Outハンドル、再生ヘッドのすべてがパーセント中央基準 (`transform: translateX(-50%)`) で統一され、終了点とキャレットが同じ時間を指している時に1ピクセルも狂わず完全に一致。
   - **上下2段セパレートトラック構造**:
     - **上段（映像トラック）**: 高精細なサムネイルストリップを独立表示。映像のシーンや動きが邪魔されずクッキリ確認可能。
     - **下段（音声トラック）**: ダーク背景の独立トラック上に、シアン〜エメラルドの上下対称オーディオ波形を明瞭描画。セリフの出だしや無音部分が鮮明に把握可能。
   - 選択範囲ハイライト領域（ドラッグで範囲全体をスライド移動可能、時間ロック中はロック外観に変化。映像・音声の両トラックを美しく包括）
   - In点ドラッグハンドル / Out点ドラッグハンドル（時間ロック中は長さを維持して全体がスライド移動）
   - 再生ヘッド（Playhead）ドラッグ追従
4. **ControlsComponent (`src/ui/Controls.ts`)**
   - 1フレーム戻る (`◀ 1f`) / 1フレーム進む (`1f ▶`)
   - 再生 / 一時停止 (`Space` キー連動)
   - 「[」キー / ボタン: 現在位置を In点 (開始) に設定（時間ロック中は長さを維持してスライド）
   - 「]」キー / ボタン: 現在位置を Out点 (終了) に設定（時間ロック中は長さを維持してスライド）
   - 「I」/「Home」キー / ボタン: キャレットを開始点 (In) へ移動
   - 「O」/「End」キー / ボタン: キャレットを終了点 (Out) へ移動
   - 選択範囲ループ再生トグル (`🔁 ループ`)
   - 再生速度セレクター (0.25x, 0.5x, 1x, 1.5x, 2x)
   - **開始時間・終了時間の左右微調整ボタン & 数値入力**: `|< IN [ ] >|` および `|< OUT [ ] >|` のように、入力欄の両側に直感的な左右ステップボタンを配置。1フレーム単位（Shift併用で1秒単位）での高精度な微調整が可能。ブラウザ標準の上下スピンボタンを非表示化し誤操作を防止。
   - **切り取り時間（長さ）の数値入力**: 直接秒数を入力すると、現在の開始点を維持したまま終了点が自動計算・反映
   - **時間ロック（Duration Lock）モード**: ロックボタンで切り替え。ON時は長さを固定したままタイムライン上で範囲をドラッグスライド移動可能
   - **デフォルト開始・終了なし（未選択）**: 動画読み込み時は範囲未選択のニュートラル状態からスタート
   - **全選択ボタン (`All` / `Ctrl+A`)**: ワンクリックまたはショートカットキーで、動画・音声の最初から最後まで（0秒〜全尺）を一発で選択範囲に設定。
   - **クイック秒数プリセット & SNSプリセット**: 3s / 5s などのワンクリック秒数指定に加え、Twitter/X (140s)、Instagram Reels / TikTok (60s / 90s)、YouTube Shorts (60s) 等の主要SNSプラットフォームプリセットに対応。
   - **選択範囲クリアボタン (`Esc`)**: スタイリッシュなルビーレッドのガラス調アクセントスタイルと `xCircle` ベクターアイコンを採用。ワンクリックまたはEscキーで選択範囲をクリア可能。
5. **ExportPanelComponent (`src/ui/ExportPanel.ts`)**
   - ✂️ **動画を切り取り保存 (MP4)**: 高速ストリームコピー (`-c copy`)、必ず `.mp4` 拡張子を付与
   - 🎵 **選択範囲の音声を抽出保存 (MP3 / WAV)**:
     - **MP3保存 (`.mp3`)**: 高品質MP3エンコード (`libmp3lame`) で出力。AIツール連携やスマホ・PC再生に最適。
     - **WAV保存 (`.wav`)**: 非圧縮PCM（16-bit）形式で劣化なく最高音質出力。編集やプロ向け音声加工に最適。
   - 📸 **現在フレームの保存 & クリップボードコピー**:
     - **PNG保存**: 最高画質PNGファイルとしてダウンロード。
     - **クリップボードにコピー**: ワンクリックで画像をクリップボードにコピーし、ChatGPT/Claude/Discord/Photoshop等へ `Ctrl+V` で直接貼り付け可能。
   - 🎬 **選択範囲ラストフレームの保存 & クリップボードコピー**:
     - **PNG保存**: 動画生成AI用リファレンス画像として保存。
     - **クリップボードにコピー**: 「続きを作る」AIツールのチャットや画像アップロード欄へワンタップで即座にペースト可能。
   - **保存先ダイアログ (File System Access API)**:
     - 対応ブラウザでは「名前を付けて保存」ダイアログが開き、ユーザーが保存先フォルダとファイル名を確認・選択可能。
     - 非対応ブラウザではブラウザ標準の「ダウンロード」フォルダへ自動保存。
   - **トースト通知**: 保存完了時・コピー完了時に画面下部にわかりやすい案内トーストを表示。
   - プログレスバー & 処理ステータス表示
6. **StatusBarComponent (`src/ui/StatusBar.ts`)**
   - FFmpegエンジンのステータス（Ready / Processing / Error）
   - ファイル名・解像度・長さ・FPS情報

## 4. キーボードショートカット
- `Space`: 再生 / 一時停止
- `I` / `Home` / `Shift + [`: キャレットを開始地点 (In) へ移動
- `O` / `End` / `Shift + ]`: キャレットを終了地点 (Out) へ移動
- `[`: 現在位置を開始地点（In）に設定
- `]`: 現在位置を終了地点（Out）に設定
- `Alt + マウスホイール`: タイムラインのズームイン / ズームアウト
- `←` / `→`: 1フレーム（約0.033秒 / 30fps換算）移動
- `Shift + ←` / `Shift + →`: 1秒スキップ
- `選択範囲ハイライトをドラッグ`: 選択範囲を維持したまま左右へスライド移動（時間ロック連動）
- `Esc`: 選択範囲を解除（開始・終了なしの状態に戻す）
- `L`: 選択範囲ループ再生の切り替え
