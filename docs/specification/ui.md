# UI 仕様書 (UI Specification)

## 1. 概要
MovieCutter は、既存の動画から必要な部分を素早く切り取り、AIツール（画像・動画生成AI）などでの続きの制作を加速するための軽量かつ直感的なWebアプリケーションです。

## 2. デザインコンセプト
- **テーマ**: Modern Sleek Dark Studio（動画編集に適した集中できるダークトーン）
- **フォント**: Inter / 'Noto Sans JP'
- **アクセントカラー**:
  - メインアクセント: Vibrant Cyan / Indigo (`#06b6d4`, `#6366f1`)
  - 切り取り範囲セレクター: Emerald Accent (`#10b981`)
  - 警告・停止: Rose Red (`#f43f5e`)
- **レイアウト**:
  - ヘッダー（タイトル、バージョン、GitHubリンク、クイックヘルプ）
  - メインビューポート（動画プレビュー・オーバーレイ）
  - タイムラインビュー（サムネイルリール、イン点/アウト点ハンドル、現在再生ヘッド、時間ルーラー）
  - クイックコントロールバー（再生/停止、コマ送り/コマ戻し、In/Out設定、再生速度）
  - エクスポートパネル（切り取り動画の書き出し、ラストフレーム/現在フレームのPNG書き出し）
  - ステータスバー（FFmpeg読み込み状況、処理進捗、ファイル情報）

## 3. 主要UIコンポーネント構成
1. **HeaderComponent (`src/ui/Header.ts`)**
   - ロゴ、タイトル
   - バージョンバッジ (`v0.0.1-beta.X`)
   - ドラッグ＆ドロップファイル入力ボタン
2. **VideoPlayerComponent (`src/ui/VideoPlayer.ts`)**
   - HTML5 `<video>` 要素
   - 再生/一時停止、シーク
   - アスペクト比自動調整、中央配置
3. **TimelineComponent (`src/ui/Timeline.ts`)**
   - タイムラインルーラー（秒・フレーム表示）
   - サムネイルストリップ（Canvasで動画から一定間隔でフレームサムネイルを生成）
   - 選択範囲ハイライト領域
   - In点ドラッグハンドル / Out点ドラッグハンドル
   - 再生ヘッド（Playhead）ドラッグ追従
4. **ControlsComponent (`src/ui/Controls.ts`)**
   - 1フレーム戻る (`-1 Frame`) / 1フレーム進む (`+1 Frame`)
   - 再生 / 一時停止 (`Space` キー連動)
   - 「[」キー / ボタン: 現在位置を In点 (開始) に設定
   - 「]」キー / ボタン: 現在位置を Out点 (終了) に設定
   - 選択範囲ループ再生トグル
   - 再生速度セレクター (0.25x, 0.5x, 1x, 1.5x, 2x)
   - 開始時間・終了時間・選択デュレーション（ミリ秒精度）の数値入力
5. **ExportPanelComponent (`src/ui/ExportPanel.ts`)**
   - ✂️ **動画を切り取り保存 (MP4)**: 高速ストリームコピー (`-c copy`)
   - 📸 **現在フレームをPNG保存**: AIの参照画像（Image-to-Video / Midjourney / Stable Diffusion等）用
   - 🏁 **最終フレームをPNG保存**: 「続きをAIで作る」用途にワンクリックで末尾フレームをキャプチャ
   - プログレスバー & 処理ステータス表示
6. **StatusBarComponent (`src/ui/StatusBar.ts`)**
   - FFmpegエンジンのステータス（Ready / Processing / Error）
   - ファイル名・解像度・長さ・FPS情報

## 4. キーボードショートカット
- `Space`: 再生 / 一時停止
- `[`: 現在位置を開始地点（In）に設定
- `]`: 現在位置を終了地点（Out）に設定
- `←` / `→`: 1フレーム（約0.033秒 / 30fps換算）または微小時間移動
- `Shift + ←` / `Shift + →`: 1秒スキップ
- `L`: 選択範囲ループ再生の切り替え
